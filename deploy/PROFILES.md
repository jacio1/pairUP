# Публичные профили

## Поведение

`/profile` — собственный профиль с редактированием в диалоге. `/users/:id` — публичная страница, доступная без входа. Автор в карточке и подробностях объявления ведёт на эту страницу. Обложка, цветной аватар, описание, учебные интересы, цель, расписание, дата присоединения и число объявлений берутся из сохранённых данных; рейтинги и подписчики не имитируются.

Данные больше не хранятся только в браузере: модель `PublicProfile` в PostgreSQL связана с автором объявлений. Публичный ответ формируется через явный select, без cookie/tokenHash, email и полей доступа. Изменять можно только собственный профиль через `/api/me/profile`; переданный клиентом id/роль/владелец игнорируется. Обновление проверяет версию документа и в одной транзакции обновляет имя автора в объявлениях.

Текущая авторизация остаётся прежней: разные браузерные TEST-сессии имеют отдельные профили. Истечение или выход из сессии не удаляет публичный профиль и опубликованные объявления; восстановление доступа после завершения TEST-сессии не реализовано. Постоянные аккаунты при полноценной регистрации потребуют связи профиля с индивидуальным User, а не временной TEST-сессией. Для исходного English создан отдельный публичный автор Alex.

Ранее сохранённый `pairup.study-profile` не удаляется: при первом открытии редактора нового, ещё не изменённого серверного профиля его значения доступны как черновик и переносятся только после явного сохранения.

## Обновление

`npm run db:generate --prefix server` и `npm run db:migrate --prefix server`, затем перезапустить приложения. Миграция `202611130002_public_profiles` создаёт профили для существующих авторов и связывает их с объявлениями; существующие объявления и комнаты не удаляет.

Карточки объявлений имеют фиксированную высоту 340 px на мобильном и 352 px начиная с sm. Нижний блок не сжимается; длинные поля сокращаются в карточке и полностью доступны в подробностях.

## Проверки

`npm test --prefix server` — валидация, запрет приватного чтения/записи без авторизации, паритет RU/EN и регрессионные проверки.

`npm run test:profiles --prefix tools` — реальные браузеры и локальная база: два разных TEST-профиля, открытие авторов с карточки и страницы объявления, просмотр без входа, сохранение/отмена, ошибка сети с сохранением текста в диалоге, защита от подмены владельца и конфликтов версий, актуализация имени/аватара, сохранность публичной страницы после выхода, одинаковые высоты карточек и мобильные размеры в обеих темах. Создаются и удаляются только собственные тестовые данные.
